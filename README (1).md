# Frontend evidence handoff

The code workspace did not contain an installed browser binary, so no screenshot is fabricated in this package.

After deploying the frontend-only update:

1. Open `https://grant-lock.vercel.app/`.
2. Scroll to **Submit a grant**.
3. Enter a valid non-zero grantee wallet.
4. Leave the acknowledgement unchecked so the disabled **Run semantic grant** button is visible.
5. Capture the complete confirmation panel, including the full 42-character wallet, permanent-holder warning, no-admin/no-recovery disclosure, checkbox, and disabled button.
6. Save the image as `docs/evidence/grantee-wallet-confirmation.png`.
7. Upload it with the remaining GitHub files and replace the screenshot row in `TESTING.md` only after the image exists.

Do not include seed phrases, private keys, wallet extension popups, or unrelated browser/account data in the screenshot.
